# React Native UI Challenge

An Expo and React Native currency exchange UI.

## Project structure

- `App.tsx` is the app entry point.
- `src/assets/` contains images, icons, and fonts.
- `src/components/` contains reusable interface components.
- `src/screens/` contains app screens.
- `src/constants/` contains shared design tokens.
- `src/types/` contains shared TypeScript types.

## Get started

Install dependencies with `npm install`, then start Expo with `npx expo start`.
